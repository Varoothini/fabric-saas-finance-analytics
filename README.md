# SaaS Finance Analytics on Microsoft Fabric

An end-to-end analytics platform for a fictional B2B SaaS company, built on Microsoft Fabric with a medallion Lakehouse, a Direct Lake semantic model, and a CFO-style Power BI report. It tracks recurring revenue, retention, and budget performance in one place.

> **Status:** Work in progress. Phase 1 (synthetic data and bronze layer) is done. See the [roadmap](#roadmap).

## Business scenario

**Helio Cloud** is a fictional B2B SaaS company selling a collaboration platform on three plans (Starter, Pro, Enterprise) to customers in North America, EMEA, APAC, and LATAM. Customers pay per seat, billed monthly or annually, and the company has grown from a handful of accounts in January 2023 to roughly 1,200 active customers and about $30M ARR by October 2026.

The CFO needs one trusted view that answers three questions:

1. **Are we growing?** MRR and ARR, split into new, expansion, contraction, and churned revenue.
2. **Are we retaining customers?** Net and gross revenue retention, logo churn, and cohort behaviour by signup month.
3. **Are we hitting budget?** Actual versus budget across the P&L, with drill-through to accounts, plus collections health (DSO).

Today these numbers live in separate extracts and spreadsheets. This project consolidates them into a governed model that refreshes automatically and respects regional access rules.

## Data

All data is synthetic and generated by [`src/saas_data_generator.py`](src/saas_data_generator.py). It is deterministic (seeded), so history never changes between runs and new months can be appended to test incremental loads.

| Table | Grain | Notes |
|---|---|---|
| `customers` | one row per customer | segment, region, industry, channel, billing cycle |
| `subscriptions_monthly` | customer x active month | plan, seats, MRR. Churned customers simply stop appearing |
| `invoices` | one row per invoice | due and paid dates for DSO; annual plans billed up front |
| `marketing_spend` | month x channel | feeds CAC |
| `chart_of_accounts` | one row per account | Revenue, COGS, Opex |
| `financials` | month x account x scenario | Actual and Budget |

Key design choices:
- **Movement labels are not provided.** New, expansion, contraction, and churn are derived in silver and gold with window functions.
- **Budget is derived from actual** with a yearly bias, so the report tells a realistic story (ahead of budget in 2024, behind in 2025 and 2026). It is a demo budget, not a real forecast.

## Planned data model (gold)

- **Dimensions:** `DimDate`, `DimCustomer`, `DimPlan`, `DimAccount`, `DimScenario`
- **Facts:** `FactSubscription` (MRR and movement type), `FactInvoice`, `FactFinancials`

## Planned report pages

1. Executive summary: ARR, NRR, churn, budget status
2. MRR waterfall
3. Cohort retention heatmap
4. Budget vs actual P&L with drill-through
5. Collections and DSO

Row-level security limits regional managers to their own region.

## How to run the data generator

1. Create a Fabric workspace and a Lakehouse.
2. Create a notebook, attach the Lakehouse as the default lakehouse, and paste in `src/saas_data_generator.py`.
3. Run it. Six CSV files are written to `Files/bronze/saas/`.
4. To simulate a new batch arriving, change `AS_OF` (for example to `2026-11-01`) and run again. History is identical and one new month is added.
